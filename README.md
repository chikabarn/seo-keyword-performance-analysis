# 📊 SEO & Keyword Performance Analysis

## 📌 Project Overview
This project analyzes SEO keyword performance over a 24-month period to evaluate
ranking improvements, organic traffic growth, and revenue impact.

The objective is to understand how **SEO efforts compound over time** and how
ranking improvements translate into measurable business value.

---

## 🧰 Tools & Technologies
- **Excel**
- **Power Query (ETL & data transformation)**
- **Excel Data Model & PivotTables**
- SQL-style analytical modeling (joins, aggregations, time-series analysis)

> Note: All transformations and analysis were performed using Power Query and
> Excel’s Data Model, applying SQL-equivalent concepts.

---

## 📂 Dataset Description
Synthetic but realistic SEO data designed to mirror real-world marketing analytics
workflows.

### Tables Included
- `keywords.csv` – keyword metadata (difficulty, intent, search volume)
- `keyword_rankings.csv` – keyword rankings over time
- `organic_traffic.csv` – impressions, clicks, CTR, average position
- `revenue_conversions.csv` – conversions and revenue attribution

### Dataset Scale
- 2,000 keywords  
- 48,000 ranking records  
- 48,000 traffic records  
- 48,000 revenue records  

---

## 🔍 Key Analyses Performed

### 1️⃣ Keyword Ranking Trends
- Tracked average Google rank by month
- Identified keywords entering **Top 10** and **Top 3**
- Measured ranking velocity for high-difficulty keywords

### 2️⃣ Traffic Impact Analysis
- Analyzed clicks, impressions, and CTR by keyword
- Applied Pareto (80/20) analysis to identify traffic-driving keywords
- Compared average position vs CTR to validate SEO performance patterns

### 3️⃣ Revenue & SEO ROI
- Linked keyword performance to conversions and revenue
- Identified top revenue-generating keywords
- Evaluated long-term sustainability of SEO efforts

## 🧠 Key Insights
- Keywords that entered the Top 5 experienced a significant uplift in CTR
- Transactional keywords generated the majority of SEO-driven revenue
- High-difficulty keywords required approximately 3–4 months before measurable impact
- Rankings stabilized in later months, indicating sustainable SEO performance

---

## 🚀 Business Value
This project demonstrates how long-term SEO investments compound over time and how
improvements in keyword rankings directly influence traffic and revenue growth.

The analysis supports data-driven decision-making for SEO prioritization and
resource allocation.
